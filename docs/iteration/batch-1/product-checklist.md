# 产品负责人 5 分钟验收清单

前置：使用隔离 U1/U2，不要使用真实用户正文；每条内容标题加 `TEST-<run-id>-`。

1. U1 发布含代码块的帖子，刷新后搜索标题并进入详情，点击编辑修改标题；确认正文/代码块仍可读。
2. U2 登录后回复并点赞，返回论坛首页；确认列表显示最新回复数和赞数。
3. U2 取消赞、改踩，普通刷新详情；确认赞/踩互斥且计数没有重复。
4. U2 尝试编辑/删除 U1 帖子应被拒绝；U1 删除自己的 TEST 回复后，详情回复数减少 1。
5. 搜索 TEST 标题，切换手机宽度，打开一个无效 ID；确认搜索结果、无横向溢出和合理错误状态。

这五步只做产品复验，不代替 `test-report.md` 的 AT01–AT22。
