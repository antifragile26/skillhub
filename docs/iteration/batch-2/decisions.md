# 第二批实现决策

- 角色只来自受保护的 `user_roles`，不信任 profile/metadata；首次管理员必须由已确认的管理员或安全入口初始化。
- 历史未删除帖子映射为 `published`；历史软删除内容映射为 `unpublished`；旧问题分类映射为 `question`，其余为 `discussion`。
- 新帖子使用 `pending`，运营批准后才公开；作者修改已发布帖会重新进入 `pending`。
- 回复默认即时公开，但必须挂在已发布父帖下；运营下架回复后不计公开回复数。
- 精选与置顶分离，置顶最多三篇；下架/删除自动清除运营标记。
- 知识是独立条目，保留来源帖子和作者署名；源帖普通修改只标记待核对，源帖违规下架会联动下架知识。
- 产品点击只记录有效关联和去标识会话；同卡片同会话 30 秒内合并，指标名为“关联产品点击”。
- 应用回滚与数据库恢复分开；批二启用审核后不能直接回到绕过审核的旧程序而继续公开读取隐藏内容。
