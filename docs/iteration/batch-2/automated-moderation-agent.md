# 自动审核 Agent v1

## 能力

- 帖子提交、编辑重提和回复发布时自动触发规则审核。
- 低风险内容自动发布。
- 命中高风险词、联系方式引流、外部链接、超长内容或重复刷屏时，保留待审核并记录风险分和标签。
- 所有判断写入 `automated_moderation_runs`，运营人员仍可在 `/admin` 做最终决定。

## 安全边界

- Agent 不拥有管理员角色，不绕过用户侧 RLS。
- 不自动删除真实内容；评论风险命中时仅设为不可见，保留原记录等待人工处理。
- `automated_moderation_runs` 只允许运营角色读取。
- 当前版本是确定性规则 Agent，不依赖新的外部 API Key；后续可增加 AI 复核，但不能直接替代人工最终处置。

## 当前规则

规则版本：`rules-v1`。

- 高风险词：风险分 +70。
- 联系方式或私域引流：+35。
- 外部链接：+10。
- 超过 12,000 字：+20。
- 重复刷屏：+10。
- 总分达到 50 时转人工，否则自动通过。
